# VIAANA · MALOKA

Painel pessoal em HTML, CSS e JavaScript. A pasta `dist/` contém o app estático. Sirva essa pasta em HTTPS ou localhost para usar a instalação e as notificações.

Os dados ficam no navegador. A tela de login funciona como bloqueio local. Os lembretes notificam enquanto o app pode executar e são recuperados ao reabrir.
