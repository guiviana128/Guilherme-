# VIAANA · MALOKA

Painel pessoal em HTML, CSS e JavaScript. Sirva a pasta `dist/` em HTTPS ou localhost para instalar o app e usar os avisos.

- Agenda com calendário mensal, seleção de dia e cadastro de lembretes.
- Som com capa local, links do Spotify e YouTube e player incorporado para links compatíveis.
- Compras com links de produto salvos no aparelho.
- Logo personalizado pelo botão **Logo**. Para definir a imagem padrão do projeto, coloque o arquivo em `dist/assets/logo.png` ou ajuste `data-logo` em `dist/index.html`.

Os dados ficam no navegador. O login funciona como bloqueio local. Os lembretes notificam enquanto o app pode executar e são recuperados ao reabrir.
