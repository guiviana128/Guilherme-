# VIAANA · MALOKA

Painel pessoal em HTML, CSS e JavaScript. Sirva `dist/` em HTTPS ou localhost para instalar o app e usar os avisos.

O app tem agenda com calendário, notas da faculdade, faixas com capas e links do Spotify e YouTube, e lista de compras com links de produtos. Para trocar o logo, use **Logo** ou coloque a imagem padrão em `dist/assets/logo.png`.

Os dados ficam no navegador. O login funciona como bloqueio local. Os lembretes notificam enquanto o app pode executar e são recuperados ao reabrir.
